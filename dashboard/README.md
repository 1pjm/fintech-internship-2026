# 전세탐정 — 위험 진단 대시보드

`전세사기예측_AUC비교_SHAP추가.ipynb` 실행 결과를 "서비스화된 XAI"로 구조화한 것.
그래프 6개를 그대로 보여주는 대신, **사용자용 화면(결과 카드 + 이유 3개 + 체크리스트)**과
**관리자용 화면(모델 전체 설명 + 검증 지표)** 두 개로 나눴다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `feature_explain_map.py` | 모델 변수 → 사용자 언어 변환 테이블 (SHAP 부호에 따라 위험 높임/낮춤 문장 + 체크리스트 매핑) |
| `risk_card.py` | `build_risk_card(prob, shap_row)` — 확률 + SHAP 값을 받아 위험 등급·TOP3 요인·체크리스트로 변환 |
| `test_risk_card.py` | 노트북에 실제 출력된 매물(X_tr #17310)의 SHAP 값으로 파이프라인 검증 |
| `index.html` | 위 파이프라인 결과를 보여주는 대시보드 (Artifact로 게시됨) |

## 파이프라인 (가이드 4-3절 그대로 구현)

```
SHAP 값 계산 (노트북)
  -> build_risk_card()가 위험도를 올린/낮춘 변수 TOP3 추출
  -> feature_explain_map.py로 변수명을 사용자 언어로 변환
  -> 설명 문장 생성
  -> 체크리스트 연결
```

## 등급 컷오프의 근거

"위험" 등급 컷오프(0.80)는 임의로 정한 게 아니라, 노트북 6장(AUC vs F1)에서 실제로
F1이 최대가 되는 임계값(`best_t=0.80`)을 그대로 가져왔다 — 가이드 1절 표에서
"F1 임계값 그래프 → 운영 정책 결정"이라고 한 부분을 실제로 연결한 것.

## 대시보드 실행 예시 (실제 실행)

```bash
cd dashboard
python3 test_risk_card.py
```
